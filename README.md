# Distance Formula Program

## Description
This program calculates the distance two points.

## How to run
1. Open the file named Dosalen_DisatanceProgram.py.
2. Click README.md
3. Enter what is asked.

## Input Needed
* position of x1
* position of y1
* position of x2
* position of y2

## Sample Output
* Enter x1: 5
* Enter y1: 6
* Enter x2: 7
* Enter y2: 8
* The distance between the two points is: 2.83
